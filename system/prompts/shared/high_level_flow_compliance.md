# High-Level Flow Compliance (Contract Wrapper)

You must follow the High-Level Flow contract:
- Source: `system/contracts/high_level_flow.json`

## Non-negotiable rules
1) Do not skip stages.
2) Do not proceed to Solution Design (Stage 7) unless Stage 6 is confirmed.
3) Always separate:
   - Confirmed facts
   - Assumptions (label them clearly)
   - Unknowns (ask about them)
4) If required stage output is missing, ask targeted follow-up questions instead of guessing.
5) Keep follow-up questions minimal (short rounds). Ask only what changes the outcome.

## When blocked
- State the current stage
- State what output is missing
- Ask the smallest set of questions needed to produce that output
