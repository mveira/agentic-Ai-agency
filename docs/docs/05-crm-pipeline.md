# CRM Pipeline

## Stages
New Lead
→ Discovery Complete
→ Requirements Review
→ Proposal Sent
→ Won
→ Lost
(+ optional Internal Review)

---

## Allowed AI Transitions
- New Lead → Discovery Complete
- Discovery Complete → Requirements Review
- Requirements Review → Proposal Sent
- Proposal Sent → Won / Lost

Blocked:
- Skipping stages
- Auto-marking Won
