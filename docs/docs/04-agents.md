# Agents

## ResearchAgent
Purpose: factual research only
Cannot: write strategy or copy

## StrategyFunnelAgent
Purpose: offer and funnel design (Hormozi logic)
Cannot: write copy

## CopyMessagingAgent
Purpose: messaging and persuasion
Cannot: change strategy

## AutomationCRMAgent
Purpose: CRM decisions only
Output: strict JSON actions

## QualityControlAgent
Purpose: validation and blocking
Authority: can stop execution
